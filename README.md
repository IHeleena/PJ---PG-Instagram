Réplica da página de login do Instagram, desenvolvida com o objetivo de praticar HTML e CSS, explorando a estruturação de páginas web, estilização de componentes e reprodução de interfaces existentes.
Tecnologias utilizadas:
HTML5
CSS3
Objetivos do projeto: Praticar a estruturação semântica com HTML; Desenvolver habilidades de estilização e layout com CSS; Reproduzir uma interface conhecida, trabalhando com alinhamento, espaçamento, cores e tipografia.
